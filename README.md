# 🎓 LearnPath AI

### Intelligent Learning Prerequisite & Roadmap Generator

LearnPath AI is a Python and Streamlit-based educational application that helps learners create a structured and personalized learning path for a selected topic.

Instead of randomly choosing what to learn first, the application identifies prerequisite topics, arranges them in a logical order, estimates the required learning time, and generates a study schedule based on the learner's available time.

---

## 🚀 Features

- 🎯 Topic-based learning path generation
- 🔗 Automatic prerequisite identification
- 🧠 Personalized roadmap based on existing knowledge
- ⏱️ Estimated learning time
- 📅 Day-by-day study schedule
- 📝 Practice questions and quizzes
- 📊 Learning overview
- 🌙 Light and dark theme support
- 💻 Simple and interactive Streamlit interface
